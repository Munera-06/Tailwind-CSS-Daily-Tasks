# Day 1 – Tailwind CSS Task 1: Incredible India

## 📌 Project Overview

This is my **Day 1 Tailwind CSS Task**, created using **HTML and Tailwind CSS**.

The webpage is based on **Incredible India**, a travel and tourism-themed webpage designed to showcase India's beautiful destinations, culture, heritage, and travel experiences.

This task focuses on learning how to use **Tailwind CSS utility classes** to create and style a complete webpage without writing large amounts of custom CSS.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Tailwind CSS Utility Classes
* Responsive Design
* Flexbox
* Background Properties
* Typography
* Spacing Utilities
* Sizing Utilities
* Layout Utilities

## 📱 Responsive Design

Tailwind CSS responsive utility classes are used to make the webpage adaptable to different screen sizes.

The design can be adjusted for:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

Responsive classes help maintain proper spacing, alignment, sizing, and layout across different devices.

The main purpose of this task is to understand the basics of **Tailwind CSS** and learn how utility classes can be used to design a complete webpage.

This task helped me practice creating layouts, styling content, managing spacing, working with responsive classes, and building a travel-themed webpage using Tailwind CSS.
