# Day 8 – Tailwind CSS Task 8: Product Website

## 📌 Project Overview

This is my **Day 8 Tailwind CSS Task**, created using **HTML and Tailwind CSS**.

This project includes two related webpages: a main **Home page** and a **Products page**. The webpages are designed to present a clean product-focused website with attractive sections, product displays, images, and organized content.

This task focuses on practicing **Tailwind CSS utility classes** to create structured layouts, style different sections, manage spacing, and build responsive webpages.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Tailwind CSS Utility Classes
* Responsive Design
* Flexbox
* Typography
* Background Properties
* Spacing Utilities
* Sizing Utilities
* Image Styling
* Layout Utilities

* Mobile devices
