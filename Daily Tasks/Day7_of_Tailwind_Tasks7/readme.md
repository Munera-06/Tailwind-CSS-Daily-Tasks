# Day 7 – Tailwind CSS Task 7: Watch Store

## 📌 Project Overview

This is my **Day 7 Tailwind CSS Task**, created using **HTML and Tailwind CSS**.

This project is based on a **Watch Store** theme and includes two webpages: a main watch store page and a collections page.

The webpages are designed to showcase watches, collections, product information, and shopping-related content using a clean and modern layout.

## 🛠️ Technologies Used

* HTML5
* Tailwind CSS
* Tailwind CSS Utility Classes
* Responsive Design
* Flexbox
* Typography
* Background Properties
* Spacing Utilities
* Sizing Utilities
* Image Styling
* Layout Utilities

## ⌚ Watch Store Webpage

The **watchstore.html** page is designed as the main webpage for the watch store.

It contains watch-related content presented through different sections.

The webpage includes:

* Watch store introduction
* Hero/banner section
* Featured watches
* Watch collections
* Product images
* Product information
* Navigation elements
* Shopping-related content
* Call-to-action sections

Tailwind CSS responsive utility classes are used to make both webpages adaptable to different screen sizes.

The layouts can be adjusted for:

* Mobile devices
* Tablets
* Laptops
* Desktop screens

Responsive utilities help maintain proper sizing, spacing, alignment, and layout across different devices.
