# Day 6 – Tailwind CSS Task 6: Bakery and Dessert

## 📌 Project Overview

This is my **Day 6 Tailwind CSS Task**, created using **HTML and Tailwind CSS**.

The webpage is based on a **Bakery and Dessert** theme, designed to showcase delicious bakery products, desserts, and related content in a clean and attractive layout.

This task focuses on practicing **Tailwind CSS utility classes** for creating webpage sections, styling images, managing spacing, applying typography, and building a responsive layout.
